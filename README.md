# Python Beginner Projects

A collection of small Python programs created while learning and practicing fundamental Python programming concepts.

## Overview

The repository contains beginner-level exercises that focus on writing simple interactive programs and applying core Python concepts through small practical problems.

## Concepts Practiced

- User input and output
- Variables and data types
- Arithmetic operators
- Conditional statements
- Loops
- Functions
- Basic validation
- Simple problem-solving

## Examples

The repository includes small programs such as:

- Calculator
- BMI calculator
- Password checker
- To-do list
- Number and string based exercises
- Other beginner programming practice

## Example: Calculator

The calculator program accepts two decimal values and an operator from the user, then performs the selected arithmetic operation.

## Purpose

This repository serves as a learning record for building confidence with Python syntax, programming logic, and basic problem-solving before applying Python to data analysis projects.
